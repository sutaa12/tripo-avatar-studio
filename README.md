# Avatar Studio

ブラウザ内でカメラや録画の動きをアバターへ反映し、背景・共有画面・アバター・文字を合成するモデル確認用アプリです。映像と音声を外部へ送信する機能はありません。

`npm ci` の後、`npm run dev` で起動します。`npm run build` は原本の VRM から画質を変えずに配信用ファイルを分離して `dist` を作ります。原本は `model-source/avatar.vrm`、生成物は `public/models` です。

「モデルの動作を確認」から「大きく動かして確認」を押すと、カメラなしで腕・指・上半身・顔の動きを確認できます。カメラと画面共有には HTTPS または localhost が必要です。画面共有と録画はブラウザによって対応状況が異なります。

現在はモデルの試作版です。目の中間形状、髪の毛先、首と襟の接続、表情の種類には制作が残っています。
