# Avatar Studio

ブラウザ内でカメラや録画の動きをアバターへ反映し、背景・共有画面・アバター・文字を合成するモデル確認用アプリです。映像と音声を外部へ送信する機能はありません。

`npm ci` の後、`npm run dev` で起動します。`npm run build` は原本の VRM から画質を変えずに配信用ファイルを分離して `dist` を作ります。原本は `model-source/avatar.vrm`、生成物は `public/models` です。

「モデルの動作を確認」から「大きく動かして確認」を押すと、カメラなしで腕・指・上半身・顔の動きを確認できます。カメラと画面共有には HTTPS または localhost が必要です。画面共有と録画はブラウザによって対応状況が異なります。

「BGM」の「音楽ファイルを選ぶ」で端末内の曲を選び、「再生」を押します。音量、ループ再生、再生位置を調整できます。「一時停止」は続きを残し、「停止」は先頭へ戻します。再生中のBGMは同じ音量で「合成を録画」に入ります。録画中も曲を切り替えられます。音量とループ設定は保存されますが、ページを開き直した場合は曲を選び直してください。

現在はモデルの試作版です。目尻の境界、髪の毛先、首と襟の接続、表情の種類には制作が残っています。

通常時は軽い微笑みで、開いた口は上の中央が尖り、下側が丸い栗型になります。カメラや人物の録画から口をすぼめる動きを検出すると口幅が狭まり、唇を閉じると開きも小さくなります。「モデルの動作を確認」の「口を開く」と「口をすぼめる」でも、それぞれの動きを試せます。

目の周りの赤みを肌色へなじませ、半眼では元のまつげを少し手前へ動かします。胸元と袖口は、ピンクの布と黒い飾りの色を整理しています。

まばたきが薄目になる場合は、入力欄の「まばたきの補正」を開いてください。「閉じやすさ」を右へ動かすと閉じやすくなります。カメラを開始し、「開いた目を記録」→「閉じた目を記録」の順に進めると、左右それぞれに合わせられます。閉じた目を記録するときは、ボタンを押してから目を閉じ、5秒ほど待ちます。補正は使用中のブラウザに保存します。
